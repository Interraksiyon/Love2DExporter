# Changelog

- Initial public MIT-licensed exporter release.
- Dark teal workspace, scrollable settings, always-visible targets/export action.
- Persistent Build Center, per-target status, stage progress, details and copyable report.
- Creator credit: Musa Berk Gümüş / Interaksiyon.
- Developer/studio and optional game-license fields, separate from tool/runtime licenses.

- Worker-thread builds, independent target errors, staging/rollback checks,
  and bounded handling of temporary Windows archive locks.
- Versioned Windows release ZIP, dependency notices, SHA256, and Windows CI.
